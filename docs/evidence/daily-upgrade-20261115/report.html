现在怎么使用

  1. 从原日用启动入口进入，已打开的工作台刷新页面。
  2. 照常创建任务并写清验收条件，查看完成卡中的条件评分、经验依据及待验证项。
  3. 支持的单步资料摘录、乘法练习、结构化报价任务出现验证失败时，点击“修复后自动回接本次任务”。核对路线与上限后授权这一项修复。
  4. 观察修复、原输入验证、自动采用、返工与实际验收；可以撤销本次授权。未知结果、缺失回执、撤权或预算不足时会停止。

这不是所有任务的全局自动开发开关。原“定向、协作、观察成长”共用身份与控制底座，授权、唯一工作版本、预算、隔离和执行回执继续有效。

后续验证怎么判断好坏

继续保留每次原评分与返工评分、失败、取消、迟到反证及成本。合成输入过关只计技术证据；真实任务要与不用经验的对照比较正确率、人工介入和完整token成本。样本不足显示未知，不能用成功次数替代成长结论。

现有空闲维护负责候选试验和已完成修复复核；没有新增定时任务或无限付费修复。日用完成卡可暂停本地验证。observe.py 提供一次只读快照，不执行模型或业务任务。
