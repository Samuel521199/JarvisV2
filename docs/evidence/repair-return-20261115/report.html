修复自动采用与原工作回接

2026-11-15 · v0.1.9 开发验收 · 日用应用未采用

三类受支持任务完成了有界闭环。

一次明确授权 → 隐藏检查 → 原输入影子验收 → 精确候选采用 → 同一工作返工 → 实际交付与原要求重验。

测试输入为操作者编写的合成业务失败案例；模型和隔离执行是真实运行。不是独立真实用户任务，不证明通用智能、长期学习或节省 token。

产物与回执核验

明确限制

当前仅单步骤纯文本三域。多步骤、无独立判定器或不能完整继承的要求不自动回接。影子回执丢失停止为待处理，尚无专用自动恢复器。知识晋升、独立用户留出与长期净收益仍需后续验证。
