| 阅读体验 | 搜索、当前/归档/已删除标签、逐批显示、同名日期/标识辅助、轻动效 | 430px 窄屏无文档横向溢出，遵守减少动画设置 |

## 实测和已修正问题

[Python 回归](regressions.json)：274 个唯一测试 ID，273 通过、1 项平台跳过，0 失败/错误。包含原固定政策清单和项目/会话目录回归；Node 草稿队列的在途等待、最新修订顺序和失败阻止整理检查通过。

[浏览器结果](browser.json)：9 项检查通过，无页面脚本错误。真实组件和 HTTP 服务配合合成项目，覆盖冷启动 fragment 授权、列表分页/重命名、跨视图未发送草稿、保存失败阻止归档、删除恢复、文件预览、项目移除恢复、展开/收回和窄屏。没有真实项目修改或模型调用。

[原生结果](native.json)：实际锁定 Cargo 依赖离线编译的发布外壳，5 项检查通过。使用独立临时根和回环地址；测试启动的 WebView2 调试端口只服务该临时外壳，测试结束关闭自有进程。通过真实 Tauri IPC 和只读 Win32 观测核对同一工作台 HWND 的显示/隐藏/复用、当前会话和草稿、完整窗口直接 IPC 被拒绝。浏览器模拟不是此项原生证据的替代。

首轮浏览器草稿检查错误地在启动动画占用焦点时输入，已改为正常跳过动画后重验；失败原件保留在本机验证目录。另发现工作台携带 HTTP 查询参数会被既有严格查询门拒绝，已改为只用 fragment 传递选择上下文，未放宽查询门。原生显示状态是异步完成，改为等待实际可见状态，再核对隐藏和复用。

截图及编译产物只放在本机 E:/Jarvis/validation 和开发 user-data，不提交 Git。没有据此给任务质量、长期学习或模型效果加分。

## 日用采用与旧外壳启用

现有旧外壳缺少正常保存后自动换壳的接口。更新新二进制登记可逆，旧二进制保留；运行中的旧进程需要主人先保存输入、从托盘正常退出，再使用新登记启动，不能为了升级强制结束未核对的草稿。后台 Host 与任务独立于精灵进程。

应用沿原固定控制器独立检查、备份和相容采用；旧版数据格式及项目路径不迁移、不重建。采用前记录原聊天、学习、待办、项目行摘要，以及模型凭据/离线模型选择摘要，采用后比较。等待网络/授权的旧工作保留，不为达到空闲门而取消。

<a id="workspace-companion-remaining"></a>
## 适用边界

没有永久删除、递归删除目录、跨浏览器草稿合并、自动取消后台任务或任意窗口控制。项目文件编辑仍沿原摘要/CAS 保存，离开未保存的精灵文件视图会被阻止。多显示器位置、跨系统表现、长期内存峰值和任意外部浏览器窗口收回未在本轮重新验证。
