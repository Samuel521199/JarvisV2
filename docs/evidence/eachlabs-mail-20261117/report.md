## 邮件界面与共用机制

精灵使用有限列表 → 正文 → 返回，工作台双栏、窄屏正文优先；同一 mail-reading.js/API 和加密账号代际状态。入场 180ms、数值变化 320ms，遵守系统和应用减少动画设置。本文浏览器截图保存在本机备份目录，不提交 Git。

本地分类只整理显示，不写 Gmail 标签、不改变信任与发送权限。初始安全/账单/物流/工作/学习/资讯关键词仅作提示；用户规则可纠正。没有模型调用即 0 云端 token，但尚未量化相对其他模型方案的节省比例。后续只有用户确有需要时才另行评估本地小模型，不能把规则冒称 AI 理解。

打开正文不自动授权其他动作；偏好缺省关闭，主人明确要求后可保存开启。缓存读取、网络读取和远端已读是三个步骤。列表/下载不当作阅读；隐藏/切换账号/无管理权限/离线/授权过期均不能写已读。批量确认冻结具体账号与邮件，每封都有原票据和回执；部分完成、未知、撤销冲突保留原状态。

- 209 个唯一适用 Python 测试通过，0 失败/错误/跳过：[回归摘要](regressions.json)。覆盖设置政策、DPAPI 活动撤回、图片/视觉、原邮件审阅/站立委托、开发隔离、原生摘要和旧版数据兼容。
- 浏览器实际组件 + HTTP 邮件服务验收通过：[结果](mail-browser.json)。正文可见、已读徽标 6→5、两封垃圾箱/两封撤销、个人规则、工作台正文、430px 无横向溢出、0 页面错误。全为本机合成适配器，真实邮件写入 0，模型调用 0。
- 实测发现工作台只回读 list、不回读精灵 sync 成功列表，导致两端不一致；已修正为同域列表来源。目录像素上限初次拒绝合法 4K，已对齐既有栅格限制并核对实际 Eachlabs 元数据。未通过降低门来消除失败。
- 静态架构、文档、JS 与独立发布检查在采用时记录；网页组件截图不证明原生窗口位置/点击透传已重新验收。

## 日用切换与恢复边界

当前后台默认 Eachlabs `google/gemini-3.8-flash`；另登记 Eachlabs 目录中的 3.1 Flash Lite / 3.1 Pro Preview / 3.5 Flash Lite / 4 Argon，原 Claude 选项保留。关闭自动备选，不回退 Google 官网，其他云端连接只存历史并停用。旧官方模型目录与凭据的 DPAPI 归档不由旧代码活动查找自动恢复；不恢复历史数据库来升级或回滚。

配置前备份位于本机 E:/Jarvis/backups/eachlabs-switch-20261117，原 Gmail 凭据未变。真实只读 Gmail 连接探测返回 WAITING_AUTH；网络已恢复可用，不能把授权过期当 Eachlabs 路由失败。待升级后由既有重连入口完成本人授权。

本轮不写永久删除、自动发送、全箱上传或后台模型定时调用。原 STOP、网络、账号代际、调用额度、未知不重放、开发隔离及代码相容回退继续适用。新图片档案在旧版不可运行时拒绝新请求，不能静默切回官方模型。
