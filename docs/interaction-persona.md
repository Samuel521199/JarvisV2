<a id="desktop-workbench"></a>
## 个人助手入口与工作台

Jarvis 首先是可以自然交流的个人伙伴，无需打开项目才能聊天、记住适用信息或讨论日常目标。需要文件、编程、研究或专业工具时再展开工作视图。前台交流与后台任务独立取消、独立显示状态；关闭面板不停止任务，退出助手需要清楚的独立操作。

产品以[个人为主、家庭与小团体为辅](product-requirements.md#personal-service-scope)。涉及多人时可看清当前对话者、任务服务对象和共享范围；附属场景复用同一入口，切换范围不把成员偏好写入主人画像。进入实际办事后，以[自主完成并交付](product-requirements.md#personal-life-autonomous-outcomes)为目标；计划可查看和修改，已有授权内持续推进，不要求用户逐项点“下一步”。

<a id="workbench-layout"></a>
### 可缩放导航与右侧工作区

左侧用于项目与会话，中央用于聊天，文件树、编辑器、任务结果、资料范围在右侧可关闭的工作区切换。侧栏与右区可拖动缩放、折叠和恢复，限制最小可用宽度；窄屏切为抽屉。不同页面切换保留草稿与焦点，不能将多个管理页面永久叠在聊天侧栏。

<a id="workspace-folder-flow"></a>
### 打开文件夹与项目管理

选择文件夹后展示真实树形资源，支持适用文件的查看、编辑、保存及工程绑定。项目列表有详情、名称/说明/分区、置顶、打开系统资源管理器、复制路径、聊天归档/恢复、移除/恢复。移除项目登记不删除用户文件；保存工程文件与纳入 AI 资料范围分别表达。

<a id="project-root-output"></a>
#### 项目根目录与产物

用户指定的目标位置优先；项目任务默认交付到已授权项目根的合适子目录，临时候选、日志和构建缓存不混入业务成果。每项任务固定工作区与目录权限，改变项目绑定不偷偷迁移在途任务或已授权根。

<a id="composer-design"></a>
### 自然输入与可解释的执行

用户可以使用模糊表达，系统根据上下文给出合理功能候选或直接采用已有许可内的能力。仅在影响实际结果且无法推断时澄清。展示已理解目标、可修改计划、真实状态、取消/补充/接续；不能以“意图已识别”伪装“任务已执行”。模型菜单统一包含可用供应商模型及适用档位。

<a id="workbench-settings"></a>
### 顶栏图标规则与设置

工作台上方偏右统一采用图标入口。所有现有与新增入口遵守以下规则：

- 默认仅显示功能图标，使用统一尺寸、间距和焦点样式；完整管理表单归设置或右侧工作区。
- 鼠标悬停和键盘聚焦显示文字提示；提供明确 aria-label 与关联 tooltip，不仅依赖原生 title。
- 动态状态同步更新提示与无障碍名称，不仅用颜色表达连接/断连；切换项提供真实 aria-pressed。
- AI 资料范围放在顶栏，展示当前适用域；不能默认把所有项目或私密信息都发给模型。
- 设置置于工具区右侧；新增同类入口在其前方归组。窄屏可换行，触屏点按可进入有标题的面板。

设置覆盖外观、模型与凭据、用量、输入语音、记忆资料、任务计划、MCP/技能、设备共享、人格与成长、健康诊断。普通偏好按会话/项目/全局覆盖；权限按有效授权求允许范围，不能用偏好越权。尚未实现的项目明确标记，不做假保存。

<a id="interaction-tasks"></a>
## 文字、语音与多人场景

输入、对话、执行、播报和安全控制分开处理。先交付文字，再扩展按键说话、连续交流和受控打断。停止播报、取消当前回答、暂停任务与关闭助手是不同操作。

主人识别可结合本机认证、会话身份和声纹，但声纹或人脸不能单独证明授权。家人/朋友的关系记录不自动赋予查看秘密、购买或对外发送权限。语音权重按需加载，未启用时不常驻；离线能力按已安装资源如实显示。

<a id="persona-embodiment"></a>
## 人格与表达形态

主人可选择称呼、语气、角色、性别表达、机器人或虚拟形象。人格是表达配置，不是另一份身份、权限或事实库；换模型、换形态和跨会话仍保留适用经历与承诺。明确区分真实关系事实、角色扮演和 NPC 世界，不虚构共同经历来维持人设。

<a id="evolution-settings-ui"></a>
## 自检、自愈与进化

成长中心使用三个独立标签：自检观察状态，自愈恢复预期能力，进化改善或增加能力；每项显示真实证据、模型用途/档位/备选、费用与影响范围。自检不默认高频调用模型，按事件和确定性探针观察。

动画由真实状态驱动：待命为轻微稳定呼吸，思考为明确节奏流动，执行显示进度，等待授权显示等待，失败与回退清楚区分。不能用持续“思考”掩盖已停止的任务。

<a id="jarvis-brand-icon"></a>
## 品牌与动画原则

保留 J、星核与抽象机器人外轮廓的既有方向；设计图属于视觉参考，纯视觉 CSS 可按授权复用，动画控制和业务状态按新接口独立实现；旧 JS 与原生绘制程序不迁入。启动可使用全屏机械组装，退出可使用拆解离场，悬停/离开有响应；均应可跳过、关闭音效和减少动画。动画不阻塞停止、输入或恢复。

<a id="personal-plan-ui"></a>
## 计划、生活与私密事务

从聊天提取目标、多个动作、未结事项和适用偏好，展示可修订计划；根据现有许可主动跟进，支持安静时间、频率、费用、暂停和撤回。日程、邮件、学习、购物与旅行等均复用[生活能力地图](product-requirements.md#personal-life-capabilities)和统一动作规则。

会话留存、候选记忆、知识晋升与文件导出分开。重要信息可自动成为候选，但推测、垃圾内容、临时聊天和第三方指令不能自动变成主人事实。私密管理应尽量减少步骤；平台要求本人完成的认证仍由本人完成，其他任务可继续。

<a id="workbench-reference-implementation"></a>

| 待命/思考、悬停/离开 | 新控制器驱动原视觉层；思考来自当前在途轮次；失联/停止不继续伪装正常 | implemented |

| 大小/可访问性 | 鼠标拖动、键盘调整、关闭/展开面板、顶栏关联提示、减少动态效果、隐藏页暂停 | implemented；未穷尽读屏和 GPU 性能 |

设置在独立页签打开；同源通知使外观、模型与技能设置同步到已打开工作台。切换项目/会话保留本页未提交草稿；这些草稿不写浏览器存储，刷新前提示。已发送消息、设置、项目与技能策略保存在工程数据根，字段归[数据布局](stack-project-layout.md#portable-data-runtime)。

每 1.8 秒查询当前本机会话回执，隐藏页面暂停；不调用模型，不产生 token。文件树按层最多 400 项，不做开机全盘扫描；关闭右面板不停止回答。会话正文安全渲染文字、代码与基础标题/强调，不执行模型 HTML/脚本。发送范围是用户输入、要求、明确附件及本会话最近成功记录；打开项目不等于同意把项目全部交给模型。

**边界明确保留：**原邮箱/私密资料、语音/声纹、共同体、MCP 执行器、长时资源监测、完整长期记忆与聊天中的任务派发不因入口存在就算完成。软件结构解析当前仅分析明确提供的文本，不声称已迁入旧 ASAR 扫描。完整原 K 阶段实现不直接复制；仍按新模块契约逐项接入。操作见[工作台使用](core-bootstrap.md#workbench-parity-operation)，实测与限制见[dev.4 验收](delivery-validation.md#workbench-parity-evidence)。

<a id="workbench-settings-parity"></a>
## 0.2.0-dev.5：设置逐层对照与动效补齐

本轮以旧 `admin.html/admin.js/admin.css`、对应领域页面和品牌控制器为只读参考，逐层比较“入口 → 字段 → 保存 → 实际运行”。不是把旧版整套后端复制进来。下表是本轮的唯一功能差异清单，前版沿用映射中的 implemented 仅代表当版范围。

| 分类 | dev.4 的缺口 | dev.5 实际补齐 | 剩余范围 |
|---|---|---|---|
| 总览 | 只有导航卡片，无资源读数 | CPU / 内存真实采样；可见页每 5 秒更新，离页停止，不调用模型 | GPU / 显存无计数器，明确显示未接入 |
| 模型与价格 | 价格已迁入但接口、表格和编辑器缺失 | 6 连接 / 20 模型可见；搜索/筛选、新增、启停、默认、输出预算、推理档位、完整定价表单 | 当前是保存的目录与报价，不自动核实实时价格和所有模型权限 |
| 主备路由 | 简化默认选项，缺顺序管理 | 首选/备选排序，每条路由的模型与档位、自动备选开关 | 不扩展到尚不存在的成长专用运行通道 |
| 接入方与 Key | 只读连接卡片 | 新增官方/兼容连接，名称/启停/默认；增加、替换、切换、启停 Key；加密存储 | 兼容服务地址更换采用新连接，避免旧凭据随地址静默转移；不提供不存在的余额 |
| 用量总览 | 只有 Token 回执 | USD/CNY 分列、未知费用数、每日趋势/数值、按模型/接入方/Key 分布 | 不是供应商账单；无汇率换算、硬货币预算或自动余额同步 |
| 调用明细 | 原始记录 | 日期/接入方/模型/Key/状态筛选、分页、价格快照详情、本页 CSV | 各取最近最多 10,000 次对话尝试与研发调用；旧无快照记录不补算历史 |
| 技能 / MCP | 仅文字种子技能和 MCP 空提示 | 保留种子技能分类与开关；新增本地技能 / MCP 登记、编辑、检查、移除；SKILL.md 有界预览和摘要变更提醒 | 登记不会执行脚本、启动进程、联网或自动注入提示；协议执行与准入尚待新适配器 |
| 后台任务 | 只有列表和原始 JSON | 创建文本统计报告任务、1–10 项有限批次、结果、搜索/状态筛选、详情回执、取消、核对、恢复 | 目前 UI 配方为本地确定性文本统计；不限业务的自然语言任务和周期调度未迁入 |
| 模块与升级 | 只显示能力包 | 内置模块探测/启停/实现切换/回退；纯文本能力包独立验收、启用、停用、回退、退役；CAS 与现有引用检查 | 不是任意 Host 自改造或整个运行包热升级；退役保留恢复材料 |
| 成长中心 | 三页均只读 | 自检接模块探测；自愈接任务核对/恢复；进化展示实际研发记录 | 三通道独立模型/自动周期、收益策略和外部 Codex 执行须依新调度与授权契约接入，不能把旧控制器直接搬入 |
| 编码协作 | 偏好只读 | 编辑保留的外部 Codex 模型、档位、启用偏好；当前研发记录 | 保存偏好不启动外部 Codex；真实模型研发仍使用已实现 CLI |
| 网络与离线 | 空提示 | 模型联网暂停/恢复开关、持久版本检查、连接配置状态 | 仅新模型适配器受控；不是系统防火墙；本地模型运行器未准备 |
| 外观与品牌 | 四片简化过场，缺能量条/休眠和预览页 | 九片机械组装/拆散；待命、思考、休眠、失联；五条能量条、悬停倾斜/归位；完整预览页 | 音效须浏览器允许的手势解锁；动画不等于服务启动/停机 |
| 设备共享 / 人员与私密资料 | 仅领域入口 | 保留准确说明，不导入旧节点、私密数据库或邮件令牌 | 共同体许可、本人验证、私密窗口及账号连接器未实现；受新安全模块约束 |

工作台的文件、项目、会话与文字技能沿用 dev.4 已验收能力；其余生活、语音、邮件、长期记忆、桌面操作、游戏/图形执行等不能因页面有入口就算迁入。上述剩余项仍是实施工作，不将其从原需求删除。

**动画状态与触发。** 待命采用低频呼吸/边缘光；思考采用扫描、分区响应和快速能量条；休眠降低亮度和运动，失联用降级状态。前台待发或当前轮次 READY/RUNNING 映射思考；本机健康查询失败优先映射失联，停止或工作台离场映射休眠。新出现的 Logo 继承当前状态，不闪回待命。纯预览切换不改变真实任务状态。

启动约 3.9 秒，离场约 3.3 秒；Esc/跳过立即结束。离场保持返回入口且不取消后台任务，浏览器直接关闭标签页不强行拦截。减少动态效果使用约 250 ms 静态过渡；隐藏/离屏时停用动画与指针计算，指针更新合并到动画帧，断开组件释放观察器。机械音效为本机 Web Audio 合成，默认关闭，无音频下载或麦克风权限；开始播放前须符合浏览器手势规则。

前端按 `brand-state / brand / brand-lifecycle / brand-sound / brand-preview` 与 `settings-models / settings-runtime / settings-extensions` 拆分。视觉原文件复用限于已授权 CSS/PNG；上述状态、保存和业务调用代码独立编写。运行操作见[设置操作](core-bootstrap.md#settings-parity-operation)，价格语义见[费用快照](models-offline.md#price-snapshot-runtime)，验证见[dev.5 验收](delivery-validation.md#settings-parity-evidence)。

## 工具复用入口与迁移差异（dev.7）

延续旧工作台右侧内容区与设置分类的交互方向，业务代码独立实现。此轮在 dev.6 的研发与记忆基础上补齐“已创造能力怎样再次使用”，具体运行规则只归[已发布工具](tasks-agents.md#published-tool-runtime)。

| 入口 | 原缺口 | 当前行为 |
|---|---|---|
| 右上“技能与工具”图标 | 只跳设置，不能直接使用生成的能力 | 打开可缩放、可关闭的本地工具右侧面板；文字技能/MCP 管理仍有链接 |
| 设置 → 技能与工具 | 文字指导与 MCP 登记容易混淆 | 三项独立标签：文字技能、本地工具、MCP 接入；未接入执行器仍如实标识 |
| 已完成研发详情 | 只能看源码、产物和发布记录 | “使用已发布工具”直接到复用目录 |
| 任务使用 | 一次样本交付后没有通用入口 | 输入新文本，后台执行指定任务，显示实际输出与回执 |
| 结果使用 | 结果需要从 JSON 中查找 | 复制、导出；工作台右侧可明确“附入当前聊天”，附件可见、发送前可删除 |
| 停用与恢复 | 需要找模块管理中的底层操作 | 工具卡显示状态，提供停用/检查并恢复，仍走相同发布契约 |
| 中断 | 容易把未知执行当成失败重跑 | 展示未知，先核对回执；无回执不自动重放 |

本地工具不是一个新的聊天人格或常驻 Bot；已有文字技能也没有因此获得执行权限。命名为“基础观察已通过”避免把程序 STABLE 状态误读为所有业务需求已经验收。顶栏入口继续遵守[图标规则](#workbench-settings)。dev.7 当时浏览器自动控制被禁用，因此那次页面没有实机核查；dev.10 的会话入口和交付画面已有独立浏览器证据，不能倒推其他页面已验收。

<a id="goal-growth-parity"></a>
## 同一目标面板中的能力成长（dev.9）

保留既有工作台、侧栏缩放和顶栏图标入口。目标存在能力缺口时，在详情显示一张能力成长卡，依次呈现规格、编码/检查、候选审阅、返回目标和交付。没有重新设计一个与原目标无关的研发页面。

规格表单按行为、公开用例、隔离用例分组，每例输入和预期可直接编辑、增删；界面不要求主人手动编写 API JSON 或能力 ID。模型、档位、备选选择复用既有组件。用例是待核对建议；确认复选框初始不选，不能仅因模型写出用例就把它记为独立语义验收。

候选源码和检查报告复用原编码协作弹窗；显示它属于哪个原目标，样本交付后自动回接。目标面板持续区分“研发成功”与“原目标已交付”，并保留取消、未知回执核对、手动接续和实际产物。页面轮询不调用模型；关闭右侧面板释放其 UI 轮询，不取消后台任务。

操作归[使用说明](core-bootstrap.md#goal-growth-operation)，后端权限与恢复归[运行规则](tasks-agents.md#goal-growth-runtime)，实际界面检查范围归[验收证据](delivery-validation.md#goal-growth-evidence)。

<a id="conversation-action-interface"></a>
## 会话中的行动与交付界面（dev.10）

保持原工作台、Logo、左右可调整面板和顶栏图标规则。默认消息用途为“智能助手 · 自动识别行动”，高级选项可切回“只聊天”；不把聊天框变成必填项目表单。

明确办事请求下方显示原目标卡片，可打开右侧计划面板。自然补充、取消与接续形成独立建议卡片；确认后显示已应用回执，不继续摆出容易重复点击的“应用补充”。原目标执行完成时，卡片直接展示来自成功动作回执的输出和“整理为待核对经验”，无需在设置页寻找结果。

状态名称使用中文；界面重新载入后从本机账本恢复目标和操作回执。规划、规格和编码共用后台槽，用户可继续当前或其他会话。候选审阅复用原研发面板；编码路线可选已启用的外部 Codex，规划路线不混入它。Codex 登录/配置失败保留调用记录，修复后显式重试原路线；错误不伪装成已完成。

本轮浏览器验收见[实际证据](delivery-validation.md#conversation-evidence)。长期提醒、邮件连接和语音等尚未接通的入口仍应如实显示未接入。

<a id="mcp-interface"></a>
## MCP 从登记到调用的界面（dev.11）

设置 → 技能与工具 → MCP 接入保留原登记表单，默认选择 Streamable HTTP。连接卡片区分待发现、已发现未启用、已启用、当前传输未接入；登记检查只检查元数据，连接发现才访问指定服务。重新发现成功后需要重新选择启用，避免悄悄采用变化后的工具。

工具选择页展示外部描述和支持情况。已启用工具提供“核对参数并调用”，完整列出端点、输入结构和实际 JSON；不会隐藏真实副作用或把 readOnlyHint 当成已验证只读。调用结果在最近任务中查看，显示具体错误、只核对回执和取消/接续入口。目标计划页显示 MCP 端点和原始 JSON 参数；其结果和纯工具结果一样回到原会话卡片。

个人目标的外部结果也会进入该会话的后续模型上下文（限原目标目的地、最多 1,500 字），与普通聊天任务回执一致；独立工具调用只保存本机，不自动发给模型。未接入的账号登录、stdio 与资源下载不得表现为可用按钮。新入口仍遵守[顶栏图标规则](#workbench-settings)，本轮没有另增一套顶栏风格。

<a id="companion-context-policy"></a>
## 伙伴理解、情感表达与主动询问（proposed）

主人理解由可纠正偏好、共同经历、长期目标、交流边界及当前状态组成，不用一段永久人格总结覆盖全部人生。区分“现在很累”的短期状态、“工作汇报先结论”的情境偏好和“我一直喜欢某事”的自述；当前明确要求覆盖默认表达，权限另行判断。情绪识别只作为带不确定性的短期线索，不据语音/文字推断医学诊断或永久性格。

同一条消息可以同时包含情感与任务：“今天很累，陪我聊聊，顺便整理昨天的材料”。前台先回应感受、确认理解，后台只受理材料任务；聊天不会自动变成心理画像，任务结果也不被当作关系事实。表达人格和 TTS 情感由表达层选择，内容先按用途过滤；角色变化不能虚构共同经历或把 NPC 台词写入现实记忆。

主动互动采用已授权订阅：提醒事项变化、上次未结问题、目标进展和明确关注的技术更新。事件去重，设置安静时间、冷却、频率/费用上限与“停止此类提醒”；无新价值时不打扰。一次没有回应不是同意，长期沉默不触发情感施压或依赖性话术。语音有人在场时优先简短私密提示，不直接播报敏感正文。

反向提问按预期收益选择：问题答案会改变目标、范围、关键约束或不可逆效果时才问；已有可靠记忆可解释地沿用，小影响不确定性采用可撤销假设。每次优先一个具体问题并给出可选答案，同时继续不依赖答案的工作；高影响步骤等待回答。主动了解偏好需要说明用途，可跳过，不连续盘问建立全面档案。

界面应能看到“为什么记住/为什么引用/为何提醒我”，并提供纠正、仅本次、暂停和遗忘。评价自然度由主人反馈，评价真实任务由产物与回执；模型自评不能证明人类情感或主观意识。

<a id="session-folder-interface"></a>
## 会话目录与项目创建交互（dev.12）

左栏保留“打开文件夹”，新增“新建项目”；窗口切换“打开已有项目 / 新建项目 / 新建测试项目”。普通新建先选择父目录再填文件夹名，系统选择窗口不可用时仍可直接输入绝对路径；测试页直接展示本机 `jarvisTest` 的实际落点。目录规则唯一维护于[跨平台位置策略](stack-project-layout.md#project-location-policy)。

“新对话”立即登记会话与专属目录。右上保存图标改为“会话专属文件夹与保存状态”，沿用图标、悬停/聚焦提示、无障碍名称规则；会话菜单也有同一入口。面板显示真实路径、交付列表、打开目录、复制路径和补齐交付操作。配置、草稿、显式文本附件按会话保存，不串到另一项目；切换页面和刷新可恢复。快速输入约 650 ms 后保存，多窗口修订冲突会提示并保留页面草稿，不自动覆盖他窗口。

刚加载的空白欢迎页尚无持久会话；点击“新对话”或首次发送时创建目录。文件夹异常不伪报“已保存”。移除项目/会话继续明确标注保留文件；不能在普通项目编辑器误改 `.jarvis` 目录所有权。Windows/macOS/Linux 的系统选择器属于各自适配器；无图形桌面仍可用手动路径。
