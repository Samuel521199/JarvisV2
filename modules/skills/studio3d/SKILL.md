# Blender 3D 制作与修改

这是 Jarvis 3D 工作室的组合技能，内部阶段统一管理，不将每个步骤显示成独立技能。默认可用，执行前由现有宿主检查启用状态、Blender 依赖、输入及当前授权。技能只提供方法，不扩大模型的文件或命令执行权限。

## 做什么与如何选择

- 需要图片参考：使用 Jarvis 图片工作室，沿用所选 Google 图片模型、编辑参考和费用账本。确认各视角比例、朝向、材质是否一致；生成图不是测绘数据。
- 需要新 3D：使用 3D 工作室的模型规划或已支持的场景数据。模型输出受限 JSON，固定 Blender Worker 制作可编辑 .blend、GLB 和真实渲染；不执行模型写出的 Python，不强制调用 Claude、Codex CLI 或 Tripo。
- 用户给出多个 GLB 要组装：使用本机 `python -m tools.studio3d_assembly --request 请求JSON`，经同一 Jarvis Host/技能启停和共享渲染队列执行；网页组装表单尚未接入。先以 inspect 检查各件原点、尺度、朝向、UV/PBR，再用 assemble 的显式世界坐标变换与父子归属生成新 .blend/GLB、多视图和回读检查。各件独立归一化时不能统一缩放后直接叠放。单侧行走机构复制时保留前后方向；镜像实例不能冒充独立设计或可逐轮运动。每件最多96 MiB、合计最多2000万三角面，限定16 GiB工作进程/20分钟；不扩大普通建模入口的预算。
- 需要局部修改：优先选定原任务与部件，修改位置、角度、比例、几何参数、材质或支持的修改器。接口为 POST /api/studio3d/jobs，字段 edit=源任务ID、source_sha256=源 scene.json 摘要、changes={objects:[{id,set:{...}}],materials:[{id,set:{...}}]}，另带新任务 id。仅接受本工作室已交付的未烘焙数据模型。使用源摘要检查过期输入，生成新版本，保留原版和改动回执；共享材质会影响所有引用部件。
- 需要按图改形：已有参考与明确模型选择后，使用工作室“参考图对照修正”；这会发送参考/渲染给所选模型并计费。没有执行回执不得说“已经修改”。
- 需要游戏资产：先完成高模外观比较，再进入已有分件减面、UV、投射烘焙与 LOD。面数统计使用三角面；低模检查轮廓、法线接缝、投射漏射、材质和目标引擎表现。面数达标与 AAA 美术质量分开报告。
- 需要角色绑定、头发物理或表情：这些是有条件的角色分支。外部 Charakuru 安装不等于 Jarvis 已接通自动绑定。当前 Jarvis 工作室不支持任意 .blend/FBX 编辑、自动人形绑定或 VRM 表情导出，明确说明缺口；不要以无绑定静态 GLB 代替请求结果。

## 操作与完成标准

先从已有要求提取用途、参考、目标部件、比例/单位和交付格式，缺少会实质影响结果的信息才询问。保留语义部件名称及运动归属，不为减少对象数合死关节。普通模型交付 .blend 和 GLB；只有角色任务明确需要时才讨论 VRM。

每次修改明确“改什么、保持什么”。检查坐标轴和变换后再诊断比例或姿态，不能把一次经验中的 90° 朝向补偿套用所有模型。角色的骨架、权重、形态键和物理字段不得在格式转换中默默丢失。未知拓扑的任意雕刻不是参数修改能自动完成的能力。

保存成功、网格/格式检查、渲染比较和最终美术验收分开记录。看真实 Blender 的正面、侧面、背面及斜视图；技术合格不能替代视觉比较。若当前没有图像观察能力，标记视觉未检查。输出新旧任务、修改部件、产物位置、实际检查、简化或未完成项、真实模型费用；不要虚构评分、额度或三维细节。

装配学习时，将失败视图、修正变换、原始文件摘要与局部适用条件保存为资产案例，并使用 `Studio3DExperience.retrieve_candidates` 验证可检索/不适用时被拒绝。模型权重没有因此更新；一次案例不自动晋升为跨资产已验证方法。高三角面与4K贴图不保证参考相似度：单独检查轮廓、安装接触、倒角/孔洞、漆面/裸金属/橡胶、粗糙度与磨损；原贴图没有的风化细节不能用“已加载贴图”宣称完成。

分件贴合不能靠把外层板件埋入外壳来消除缝隙。用户指出遮挡、比例或接触问题时，撤回该局部的完成判断，保留失败版并修订案例；按板件外缘多点检查可见性，侧视核对背部支承。补做灯具等附件时检查实际底座 footprint 与安装面的坡度、横梁等凸起，不能只测中心点。外观采样通过不代表全表面碰撞、制造公差或历史尺寸已验证。先锁定基础比例与高模部件完整性，再进入材质风化或低模烘焙。

若补块造成明显接缝，且用户允许修改承接主体，优先检查主体前壳、顶面和侧面的连续过渡；在绑定原始来源和明确局部范围后再改形。保留可回退版本，检查受影响三角面的翻面/退化、未修改区域、UV及非目标部件，再用同一相机近景和整圈边界采样复核。真实板件接合线不应全部抹平。资产专用坐标配方不可套用其他模型；只允许读原件或没有可编辑主体时不得走该分支。

普通聊天只加载指导，不自动生成图片、渲染或花费模型额度。现有已明确的授权不重复询问；缺少素材、执行器或具体选择时说明所缺内容。停止/取消、依赖检查、费用和恢复沿原工作室机制。
